# 04 Performance spike

Status: desktop result in, tablet result pending. Required by ADR 0004.

## What it is

A throwaway test page at `/spike.html` (code in `src/spike/`). It loads a
128 by 128 tile map in Tiled JSON format with three layers (generated by
`node scripts/gen-spike-map.mjs`), moves a few hundred sprites,
runs the day clock, pans the camera, and shows fps, worst frame time and JS
heap in an overlay. It draws its own placeholder textures, so it needs no art.

URL options: `?sprites=500` sets the sprite count (default 300) and `?zoom=2`
sets the camera zoom (default 3). Drag to pan.

## Budget

- Desktop: steady 60 fps.
- Older tablet: 30 fps or better, no frame over about 50 ms, no browser or
  webview crash from memory.
- The oldest tablet to support is still to be chosen.

The map is a 2048 by 2048 pixel world and the camera only draws the visible
part, so the test mostly checks sprite count and loading. A real tablet run is
the part that decides this.

## Running it on a tablet

1. On the development machine run `npm run dev -- --host`.
2. On a tablet on the same Wi-Fi, open `http://<machine address>:5173/spike.html`.
3. Let it run for a few minutes, drag around, and note the overlay numbers.
   Try `?sprites=1000` as a stress case.
4. Add a row to the results table above.
