# Session Handoff: 2026-10-14 (third session)

## Summary

Planning-approach session. We looked at how large games are usually planned
(pillars and core loop first, staged milestones, a vertical slice as the gate
into full production, strict scope control) and chose to start from core ideas
and non-goals. The project brief is now drafted and merged. No code or stack
choice yet.

  layers, a proposed MVP and an explicit non-goals list.

## Risks or decisions needed

- The pillars and non-goals are provisional. Answers to the identity and
  audience questions may change them, especially "cozy first" and "home base,
  wider world".
- Real-time combat in ring 3 is the largest scope item and is a non-goal for
  now.
- A vertical slice often feels nearly done but is only about 20% of the work.
  Fix its scope before building.
- The Steam EULA was never read.
- `0001-record-architecture-decisions.md` says ADRs are date-named, but
  `docs/decisions/README.md` says `NNNN-short-title.md`. We followed the README.
- The repo `LICENSE` is the template default (GPL-3.0). Decide whether to keep
  it.
- A real name is needed eventually. A name ending in "Valley" sits close to the
  original's branding.
- Handoff filenames use the UTC date. This file is `2026-10-14c.md` because
  handoffs for that date already exist.
