## Current state

- `main` is at the merge of #65. The scene still has no tools, plot visuals,
  `GameState`, shop, hall or end screen. It still uses `Day` directly with a
  placeholder Space action.
- The map code reads the map only through `FarmMap`. Tests assert the contract,
  never the layout, so a real Tiled map can replace the placeholder. Layers
  `collision` and `soil` are required, objects are matched by `class` (`spawn`,
  `door` named `house`, `shop` or `hall`, `forage`).
- Touch has only been checked with simulated touch events in headless Chromium,
  not on a real tablet. Keyboard movement was checked in headless Chromium, and
  the spike (not the scene) was run on real devices.
- The spike scene is synthetic (flat sprites, no text or effects), so the
  performance result should be repeated on a real scene.
- Known limits: the facing marker and the player draw order are crude (the
  player is always above the object layer), and the HUD text row is long.
- Verifying in a browser: headless Chromium works through Playwright borrowed
  from `/home/richard/Projects/beaver_cycle/node_modules` (nothing is installed in
  this repo). The dev build exposes `window.farmDebug()` for position, tile,
  facing and door.

## Risks or decisions needed

- The real map design is open and shapes everything downstream. Keep the
  placeholder disposable (see the note) and avoid hard-coding coordinates.
- The SM-X200 and SM-X210 were not tested; they are newer than the SM-T500 and
  expected to do at least as well.
- Branch protection only requires `repo-hygiene`. Decide whether `build` should
  be required (in #59).
- `LICENSE` is still the GPL-3.0 template default (#63). The installed-app
  wrapper needs its own ADR (#62). World, name and lore are not invented yet.
- Auto-merge sometimes waits on a branch that is behind `main`; update the
  branch (API `update-branch`) when a PR stalls.
- Housekeeping done on the user's devices: `stay_on_while_plugged_in` was set to
  3 on the SM-T500 and reset to 0 without reading the old value first, and the
  `adb` reverse and forward entries were removed.
