## New asset: the valley map

**`docs/valley-map.html`** is an overview map of the valley. Open it from disk.
It has two tabs, the whole valley and a zoomed Hearthwell, with area names, main
buildings, ponds and gates, and all 30 people from note 20 as placeholder role
labels (a heart marks the 14 marriage candidates). Drag and zoom, click a pin for
its details and design note link, and a checkbox hides the people.

- It is built from the hand-kept **`docs/valley-map.json`** by
  `npm run valley-map` (`scripts/valley-map/build.mjs`). `npm run
  valley-map:check` is in `npm run check`. It fails on a stale page, a missing
  note link, or a people count that drifts from note 20 (30 people, 14
  candidates).
- Design note: `docs/design/56_valley_map.md`. It is a design reference only,
  not in-game Map tab art and not a layout. Positions are diagrammatic.
- Update the JSON whenever note 19 (layout), 20 (cast) or 55 (farm) changes,
  then run `npm run valley-map`. Use it as the picture when designing Hearthwell.
- The three Hearthwell homes without a shop (retired couple, gardener, young
  adults) are placeholder burrows with invented positions, because note 19 leaves
  the number of homes open.
- CLAUDE.md lists the command. CI does not run the check on its own (neither does
  it run `overview:check`); it runs through `npm run check`.
