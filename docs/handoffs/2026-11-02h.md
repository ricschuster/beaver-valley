## Summary

The session wrote the wrapper ADR (ADR 0008) and checked the multiplayer note
(53) against the saved Stardew Multiplayer wiki page.

## Completed

- **ADR 0008, #368 (closes #62):** Electron on desktop, Capacitor with a native
  host plugin on tablets, the browser as guest only. The host is plain Node and
  shared with the Node test host. `src/net/` talks to a `HostBridge` interface
  with three implementations (Electron, the Capacitor plugin, the Node test
  host). Signing, auto update, store release and installers are left for later.
  Note 53, the M4 row in `03_milestones.md` and the overview were updated.
- **Note 53 check, #369:** a "Checked against Stardew" section. Findings:
  - Stardew does not pause for menus in multiplayer, so our rule now matches.
    At 02:00 a player with a menu open does not pass out until it closes, which
    we should copy.
  - Wallet mode can change later (Stardew's Town Ledger, even split when
    separation is turned on).
  - Extra cabins cost 100 gold and are instant, a reference for our price.
  - Quests, recipes and mail are per player. Mine, museum, bridge and hall
    bundles are shared.
  - No join password, but the host can kick and ban.
  - New ideas, not decided: a profit margin set at creation (25, 50, 75, 100
    percent), a ping readout, a sleep announce setting.
  - Mobile multiplayer is experimental, and the page does not say if it can host.
- The `urls_multiplayer.txt` list was written and then deleted. The `Bed` page
  was only a redirect to Furniture, and `Saving_and_Loading` and `Sleeping` do
  not exist on the wiki.
