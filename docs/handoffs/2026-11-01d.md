## Completed

- **#311 confirmed merged** (squash, `e0f399b`, both checks green).
- **Tool upgrades (note 44, #313).** Five grades (Basic, Copper, Steel, Gold,
  Hearthsilver) for the axe, pickaxe, hoe and can. Cost is gold plus 5 bars
  (copper, iron, gold; Hearthsilver bars only, no gold). The smith dwarf keeps
  the tool for 2 days. Grades go in order. Copper axe clears large stumps, steel
  clears large logs and the Secret Woods log. Axe swings 10, 8, 6, 4, 2 a tree
  and 5, 4, 3, 2, 1 a stump. Notes 07, 19 and 22 point at it.
- **Controls (note 45, #314).** Desktop (keyboard and mouse) and touch are two
  separate profiles, never mixed. The profile is chosen once from
  `pointer: coarse` and changed only in options. Default keys are Stardew's
  (C use, X action, E or Esc menu, Tab next slot, Left Shift next row, 1 to 0,
  minus, equals for 12 slots), with Eat (F), Skills (K) and End the day (Z)
  kept as ours. Left-click uses and right-click acts (from memory). Every
  desktop key is rebindable, menu keys are fixed, no run key. A controls-only
  options screen opens from the title screen and the in-game menu. Settings are
  stored per device in `beaver-valley-settings`. Gamepads are parked.
- `docs/overview.json` and `docs/overview.html` updated for both. #314 needed
  `main` merged in first, because both PRs changed the generated HTML. Rebuild
  with `npm run overview` after a merge conflict there.
