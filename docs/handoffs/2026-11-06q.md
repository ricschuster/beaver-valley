## Summary

The owner picked the final game name, Elderglen (#138, ADR 0011). Elderfold came
first (ADR 0010) and was dropped within the session. Everything that carried the
old working title, Beaver Valley, was renamed, including the GitHub repos and
the local folders.

## Completed

- **Name chosen: Elderglen.** Elder is the elderfruit, our rare boost item, and a
  glen is a small wooded valley, so it reads as "where the elders grow". ADR 0011
  records it and supersedes ADR 0010.
- **Why not the others.** Elderfold is a real Peak District farm business with
  the domain, and "Welcome to Elderfield" is a farming game that launched on
  Steam on 10 September 2026. Elderkin is a Nova Scotia farm, Eldervale a board
  game, Elderglade a blockchain game. Names without Elder (Rowanglen, Bracken
  Glen, Sorrel Glen, Alderglen, Hazelglen) were clear but the owner passed.
- **Known overlap, accepted.** A Shire-themed fan site lists a village called
  Elderglen. A hobby page, not a business, game or trademark.
- **Code rename (PRs #455, #456, #457).** Page title, title screen, package name,
  README, CLAUDE.md and the overview page. Save keys are now `elderglen-save` and
  `elderglen-settings`; saves under the old `beaver-valley` keys are still read
  (`src/scenes/storage.ts`). Playtest scripts use the new keys.
- **Repos renamed on GitHub:** `ricschuster/elderglen` and
  `ricschuster/elderglen-private`. Old URLs redirect. Local remotes updated.
- **Private repo scripts updated:** `sync.sh` (now `ELDERGLEN_DIR`, default
  `~/Projects/elderglen`), `hooks.json`, `install-hooks.sh`, README. The
  SessionStart and SessionEnd hooks in `~/.claude/settings.json` now point at
  `~/Projects/elderglen` and `~/Projects/elderglen-private` (backup at
  `~/.claude/settings.json.bak-rename`).
- **Local folders:** renamed to `~/Projects/elderglen` and
  `~/Projects/elderglen-private`, with the Claude memory folder moved to match
  (`~/.claude/projects/-home-richard-Projects-elderglen`).
