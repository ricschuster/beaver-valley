## Completed

- #188: `docs/design/18_dialogue.md`. Decided: authored lines only (no runtime
  generation); a small base pool plus a reactive layer; strict priority tiers
  (event, hall or story, weather or season, hearts, generic); one tap for the
  daily line and a Talk button for branching; branching conversations as capped
  node graphs of about 4 to 8 nodes with a validator; branches change hearts and
  set flags (per character, plus a few named globals); hearts never fall; seen
  conversations retire with a recall journal; four release layers; a voice sheet
  per character (guide plus checklist); one JSON file per character with keyed
  strings in a separate table.
