# Session Handoff: 2026-10-15 (b)

## Summary

Chose the engine and built the project skeleton and a performance spike. The
stack is TypeScript, Phaser, Vite and Tiled maps, picked mainly because Claude
can build, run, test and screenshot it without the developer in the loop.
Installed apps will wrap the web build. The spike passes on desktop. The real
test, on a tablet, is still to do and is the next step.

## Completed

- Issue #19, engine and language: ADR 0004 accepted (PR #35). Godot 4 is the
  recorded fallback.
- Project skeleton (PR #36): Vite, TypeScript, Phaser 4, Vitest, ESLint,
  Prettier, a tested day clock in `src/core/clock.ts`, a placeholder scene, a CI
  `build` job, npm Dependabot, `CLAUDE.md` Commands and Stack, and a solo
  `CONTRIBUTING.md`.
- Performance spike (PR #37): `/spike.html`, a 128 by 128 Tiled-format map with
  300 or more moving sprites, the day clock and an fps and memory overlay.
  Desktop headless result: 60 fps, worst frame 17 ms, 30 MB heap. Notes and
  steps in `docs/design/04_performance_spike.md`.
- Opened issue #38 (`next-payoff`) for the tablet run.

## Current state

- `npm run check` runs every gate: format, lint, typecheck, tests, build.
  `npm run dev` runs the game.
- Game rules go in `src/core/` with no Phaser imports (ESLint enforces it).
- Headless browser checks work here: Playwright with the cached Chromium
  (`~/.cache/ms-playwright/chromium_headless_shell-1243`), software GL. The
  helper scripts were in the scratchpad and are gone, so write new ones.
- The desktop result used software rendering, so it says little about a tablet.
- The game scene is only a clock. No farm, map or inventory yet.

  `build` job as a required check (a repo setting, not changed so far).

- Items for the five bundles wait on the crop and forage lists.
- World, name and lore are not yet invented (ADRs 0002 and 0003).
- `LICENSE` is still the GPL-3.0 template default.

  app, to revisit if it matters.
