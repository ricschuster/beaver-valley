# Stardew Valley inspired, not derived

## Status

Accepted

## Context

This project is inspired by Stardew Valley. We found no public license or
fan-content policy that grants rights to reuse the game's assets or expression.

## Decision

We describe the project as Stardew Valley inspired. General mechanics and genre
conventions are fine. We do not reuse its name, trademarks, art, audio,
characters, text or code, and we keep our branding distinct from it.

## Consequences

- All art, audio, text, names and data must be original or properly licensed.
- Reusing anything from the game would need a new ADR that supersedes this one.
